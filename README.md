# 新商品導入フロー 進捗管理アプリ

食品加工工場（OEM・PB受託）が、新商品の立案から発売までを **8フェーズ・24工程＋5判定ゲート** で管理する社内共有Webアプリ。

- **公開URL**: https://daito-group.github.io/product-launch-flow/
- 単一HTML（`index.html`）＋ Google Apps Script（`共有サーバー_AppsScript.gs`）＋ スプレッドシートで、全員が同じデータを読み書きします。
- 商品ごとにカードで一覧し、詳細で各工程のステータス（未着手／進行中／完了／保留）・開始日・完了日・備考を記録。進捗率と現在フェーズは自動算出。

## 共有の設定

初回のみ、Google側の設定（約10分）が必要です。**[共有版セットアップ手順.md](共有版セットアップ手順.md)** を参照してください。
